1. **Menampilkan Proses:** Membuka Task Manager (`Ctrl + Shift + Esc`) untuk melihat seluruh aplikasi dan proses yang sedang berjalan pada sistem operasi.

2. **Menjalankan Aplikasi:** Membuka Microsoft Edge untuk melihat proses utamanya yang terpecah menjadi beberapa proses turunan di Task Manager demi keamanan dan kestabilan sistem.

3. **Mematikan Proses Paksa:** Menghentikan Microsoft Edge tanpa tombol keluar (`X`), melainkan melalui fitur *End task* di Task Manager atau perintah `taskkill /f /im msedge.exe` pada Command Prompt untuk memaksa sistem melepaskan alokasi *resources*-nya.
4. **Me-restart Proses:** Setelah proses dimatikan paksa oleh sistem, aplikasi dapat di-*restart* dengan membukanya kembali dari awal.
